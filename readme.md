# Marketplace API

## Project overview
This is a RESTful API for a marketplace platform, where users can register, authenticate, and manage product listings.

## Features

- User registration and authentication
- JWT-Based authentication
- Refresh token rotation and logout
- Product CRUD operations
- Product ownership validation
- Product pagination

## Tech stack

- Runtime **Node.js**
- Language **TypeScript**
- Framework **Express 5**
- Database **PostGreSQL**
- Database driver **pg**
- Authentication **JWT, bcrypt**
- Configuration **dotenv**
- Development **tsx**

## Getting started
### Prerequisites

- [Node.js](https://nodejs.org/en/download)
- [PostGreSQL](https://www.postgresql.org/download/)

### Installation

1. Install required software
2. Clone the repository. `git clone https://github.com/meipass/MarketPlace-RestAPI.git`
3. Open shell in the project folder using `cd` command
4. Run `npm install` to install all required packages and create package.json file

### Starting

1. Open shell in the project folder using `cd` command
2. Run `npm run dev`
3. Done!
